# Portfolio Website - Terminal Style

A terminal-based interactive portfolio website for software developers.

## Features

- 🖥️ Terminal-style UI with retro aesthetics
- ⌨️ Interactive command-line interface
- 📱 Fully responsive design
- 🎨 Smooth animations and transitions
- 🔍 Tab completion for commands
- ⬆️⬇️ Command history navigation (arrow keys)

## Available Commands

- `help` - Display all available commands
- `about` - Learn more about the developer
- `skills` - View technical skills
- `projects` - See portfolio projects
- `experience` - View work experience
- `education` - See educational background
- `contact` - Get contact information
- `resume` - Download resume
- `clear` - Clear the terminal
